🚀 Project Highlights

✓ Role-based auth — Student, Faculty & Admin
✓ Real MongoDB Atlas cloud database
✓ JWT secured REST API on Node.js + Express
✓ Bulk attendance & marks management
✓ File uploads — notes, assignments, lab reports
✓ Semester-wise student promotion with undo
✓ Dark & Light theme toggle
✓ Fully responsive — mobile to 4K
✓ Live deployed — Netlify + Render
✓ Android WebView app (APK available)

🏗️ Tech Architecture

🌐
Frontend Client Side
HTML5, CSS3, Vanilla JavaScript — Zero frameworks. Custom design system with dark/light themes. Deployed on Netlify CDN.
⚙️
Backend Server Side
Node.js + Express 5 REST API — JWT auth, bcrypt password hashing, role-based access control. Deployed on Render.
🗄️
Database Cloud DB
MongoDB Atlas + Mongoose ODM — Cloud-hosted NoSQL database. Stores users, attendance, marks, assignments and files.
